# GAB Review Center — MVP

Внутренняя очередь ручной проверки 140 строк реестра аренды из загруженного XLSX.

## Что есть в пакете

- `data/records.json` — 140 исходных записей с исходными OCR-полями, нормализованными значениями и предупреждениями.
- `app/schema.sql` — отдельная таблица `gab_review_records`.
- `app/import_data.py` — первичная загрузка записей в PostgreSQL. Повторный запуск не перезаписывает уже импортированные записи (`ON CONFLICT DO NOTHING`).
- `app/main.py` — API и защищённый HTTP Basic вход.
- `app/static/` — веб-интерфейс с поиском, фильтрами, очередью, карточкой записи и сохранением исправлений.

## Важные ограничения

1. Это MVP проверки **строк реестра / объектов**, а не готовый справочник уникальных компаний. Компании нужно будет отдельно дедуплицировать по ИНН, телефону и email.
2. Исходные OCR-данные хранятся отдельно и не перезаписываются. Исправления сохраняются в `corrected_fields`.
3. Пакет содержит персональные контактные данные из предоставленного реестра. Не публикуйте сервис в интернет без HTTPS, пароля и проверки доступа.
4. Привязка к существующей PostgreSQL ещё не настроена: сначала нужно безопасно сверить имя сервиса PostgreSQL, сеть Compose и доступные учётные данные. Не использовать базу `n8n` и не менять существующие сервисы наугад.

## Переменные окружения

- `DATABASE_URL` — строка подключения к отдельной базе GAB CRM (не к внутренней базе n8n).
- `GAB_APP_USER` — имя пользователя для входа в панель.
- `GAB_APP_PASSWORD` — длинный уникальный пароль.

## Подготовка базы

В отдельной базе данных GAB CRM выполнить:

```bash
psql "$DATABASE_URL" -f app/schema.sql
```

Загрузить данные один раз:

```bash
python app/import_data.py
```

Локальный запуск для теста:

```bash
pip install -r requirements.txt
export DATABASE_URL='postgresql://USER:PASSWORD@HOST:5432/gab_crm'
export GAB_APP_USER='gab-admin'
export GAB_APP_PASSWORD='CHANGE_TO_A_LONG_RANDOM_PASSWORD'
python -m uvicorn app.main:app --host 127.0.0.1 --port 8091
```

Открыть `http://127.0.0.1:8091`. Браузер запросит Basic Auth.

## Безопасная установка на сервер

Не добавлять сервис в работающий Compose до проверки текущего `docker-compose.yml`, реального имени PostgreSQL service/network и credentials. Не перезапускать `n8n`, PostgreSQL, Ollama или `gab_ocr` ради установки этого MVP.
