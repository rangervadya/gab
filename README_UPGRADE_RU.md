# GAB OCR v0.4.3 — обновление

Эта версия сохраняет API `/extract`, заголовок `X-API-Key` и совместимую структуру `pages[].tables[].rows`, `pages[].raw_text`, `pages[].coordinate_rows`.

## Что изменено

- Исправлено отнесение слов к строкам таблицы для текстового слоя PDF: вместо геометрического центра bounding box используется точка в верхней части глифа (35% высоты от верхней границы).
- Это устраняет конкретный дефект, когда нижняя часть глифа пересекала горизонтальную линию таблицы и слово попадало в следующую строку. На тестовом PDF значение площади `444,6 кв.м.` из строки «Нурлат» на странице 4 восстанавливается в правильной записи.
- Сохранены границы колонок, порядок слов, существующее резервное распознавание формата/месяца и схема ответа API.

## Проверка на исходном тестовом PDF

- 8 страниц обработано.
- 140 строк таблицы извлечено.
- Время тестового прогона: около 27,3 секунды в тестовой среде.
- Площадь `444,6 кв.м.` восстановлена в строке «Нурлат»; предупреждение `area_missing` исчезло для этой строки.
- Остальные предупреждения сохраняются для ручной проверки; версия не подставляет отсутствующие значения догадкой.

## Обновление

Сделайте резервную копию `/opt/gab/app.py`, затем обновите файлы из Git и пересоберите только сервис `gab_ocr`.

Не коммитьте PDF, `.env`, токены или выгрузки реестров.
