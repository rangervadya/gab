# GAB OCR v0.4.4 — обновление

## Что изменено

- Добавлено адресное повторное распознавание пустых ячеек колонки «Срок действия договора» (column 7).
- Для горизонтальных страниц используется OCR только точной области пустой ячейки, включая страницы со встроенным текстовым слоем и сканированные страницы.
- Для повёрнутой страницы 8 добавлен такой же резервный проход по пустой ячейке срока.
- Автоматически принимаются только значения, соответствующие ожидаемым форматам срока (`5 лет`, `1 год`, `18 мес`) или явной дате в этой колонке. Неуверенные значения остаются пустыми и отмечаются для проверки.
- Восстановленное значение помечается в `cell_ocr_fallbacks` как `lease_term`.
- Существующий API `/extract`, заголовок `X-API-Key`, структура `pages`, `tables`, `coordinate_rows` и алгоритмы других колонок сохранены.

## Проверка на исходном тестовом PDF

- Версия: 0.4.4.
- 8 страниц обработано.
- 140 строк извлечено.
- Время теста: около 29 секунд в тестовой среде.
- Все пустые значения `lease_term` из прежней версии восстановлены; в тесте 0 предупреждений `lease_term_missing`.
- 9 значений восстановлены отдельным OCR-проходом по ячейке, ещё одно значение на странице 8 распознано основным OCR-проходом.

Результаты теста не означают, что все остальные поля таблицы полностью проверены. До записи в БД сравнивайте значения с оригинальным PDF; сомнительные значения не следует исправлять догадкой.

## Обновление

Сделайте резервную копию `/opt/gab/app.py`, затем обновите файлы из Git и пересоберите только сервис `gab_ocr`.

Не добавляйте в Git PDF, `.env`, токены, секреты или выгрузки реестра.
