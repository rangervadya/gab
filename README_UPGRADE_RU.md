# GAB OCR v0.4.2 — обновление

Эта версия сохраняет API `/extract`, заголовок `X-API-Key` и совместимую структуру `pages[].tables[].rows`, `pages[].raw_text`.

## Что изменено

- Для сканированных страниц добавлен точечный OCR резервных ячеек колонок «Формат» и «Месяц окончания аренды».
- Для формата принимаются только значения `ММ`/`MM`; для месяца — только 12 русских названий месяцев. Неподтверждённые значения не подставляются.
- В ответ каждой строки добавлено поле `cell_ocr_fallbacks`, а в layout — `focused_cell_ocr_fallbacks`.
- Для оставшихся сомнительных значений добавляются предупреждения `format_value_needs_review` и `lease_end_month_value_needs_review`.
- Существующие поля API сохранены.

## Обновление

Сделайте резервную копию `/opt/gab/app.py`, затем обновите файлы из Git и пересоберите только сервис `gab_ocr`.

Не коммитьте PDF, `.env`, токены или выгрузки реестров.
